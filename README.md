# SoraFit v1.31.2

GitHub Pages向けの公開用PWA一式です。Open-Meteoを利用し、服装・アウター・傘・雨時間・1時間予報・最大16日予報を表示します。

v1.31では、**今日の最高気温・最低気温の横に、昨日との差を（+3℃）（-2℃）（±0℃）の形式で表示**します。前日データを取得できない場合は、誤表示を避けるため差分だけを非表示にします。

画面下中央の丸いショートカットから、表示中の地点に合わせたYahoo!天気の雨雲レーダーを開けます。Weather Briefにはこの先1週間の簡易見通しも含まれます。

## 公開方法

このフォルダの公開用ファイルを、GitHub Pagesの公開ルートへ同じ階層のまま上書きしてください。

- `index.html`
- `manifest.webmanifest`
- `sw.js`
- `robots.txt`
- `icons/`

`sw.js` のキャッシュ名は `sorafit-shell-v1.31.2` に更新済みです。旧キャッシュから新しい公開データへ切り替わるようにしています。

## 毎朝6時通知

Supabase側の既存バックエンド構成は変更していません。利用端末では公開URLを開き、アプリ内の「通知をON」を1回押してOSの通知を許可してください。

## 注意

招待コードはクライアント側の簡易ゲートです。強固な認証ではありません。`robots.txt` と `noindex` で検索露出を抑えています。

`.github/workflows/android-widget.yml` は既存Androidウィジェット用ワークフローを変更せず同梱しています。Web公開とは別系統です。


## v1.31.1 Weather Brief 修正
日本語音声を小分けにして再生。端末内の日本語音声を優先し、失敗時にブラウザ標準音声等へ切替。エラーコードを表示。


## v1.31.2 時間別天気の過去24時間表示
Open-Meteoの`past_hours=24`を利用して時間別データを過去24時間分追加しました。
アプリ起動直後の表示位置は今までどおり「現在」。左へのスクロールまたは「過去24時間」ボタンで遡れます。
「現在へ戻る」ボタンで直ちに現在付近へ戻り、現在列は青色で強調されます。
過去データは気象モデルに基づく推定値であり、観測所の実測データではありません。
音声、既存の16日予報、Web PushおよびAndroidウィジェットの動作コードは変更していません。
