# SoraFit FINAL v1.30

最終公開用PWA。Open-Meteoを利用し、服装・アウター・傘・雨時間・1時間予報・最大16日予報を表示します。

## 公開方法
このフォルダの内容を、GitHub Pages等のHTTPS静的ホスティングのルートへそのまま配置します。`index.html` / `manifest.webmanifest` / `sw.js` / `icons/` の相対配置を変更しないでください。

## 毎朝6時通知
Supabase側で 06:00 JST（21:00 UTC）にサーバー定時処理が稼働する構成です。利用端末では公開URLを開き、アプリ内の「通知をON」を1回押してOSの通知を許可してください。通知登録後はアプリを閉じていてもWeb Pushの配信対象になります。

## インストール
HTTPS公開後、対応ブラウザから「ホーム画面に追加」またはアプリ内のインストールボタンを利用します。

## 注意
招待コードはクライアント側の簡易ゲートです。強固な認証ではありません。robots/noindexで検索露出を抑えています。
